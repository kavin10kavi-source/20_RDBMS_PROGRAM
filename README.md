# PL/SQL Trigger – Display Message After Employee Insert

## Question

Create a trigger that automatically displays a message after inserting a new employee record into the Employee table.

## Objective

To create an AFTER INSERT trigger that automatically displays a message whenever a new employee record is inserted.

## Employee Table

The Employee table contains:

- EmployeeID
- EmployeeName
- Department
- Salary

## Expected Result

After inserting a new employee record, the trigger should automatically display:

New employee record inserted successfully.
